**要点**

- 分别在**进入 `!→LUMIX` 态之前与之后**各跑一次，结果一致

## 记录 4 · 被动监听（interrupt + bulk IN）

命令：`./s5_usb_listen 30`（进入 `!→LUMIX` 态之后）

```
[interface has 3 endpoints]
  pipe 1: EP 0x01 OUT bulk mps=512 interval=0
  pipe 2: EP 0x82 IN  bulk mps=512 interval=0
  pipe 3: EP 0x83 IN  interrupt mps=64 interval=16
[pipes] bulkOut=1 bulkIn=2 intIn=3

=== summary ===
  interrupt IN bytes : 0
  bulk IN bytes      : 0
  events seen        : 0
```

**要点**：interrupt interval=16，高速下轮询周期约 **4.1 秒**，30 秒 ≈ 7 个周期
⇒ **设备确实不主动推事件，不是"没等够"**。
