## 结论速览

| 项 | 状态 |
|---|---|
| **隐藏录制格式持久化**（NTSC + MOV + 150Mbps C4K） | ✅ **已完成并交付**（PAL `GK` 机型上实现） |
| **服务模式 / ROM BACKUP** | ✅ **打通**（门控 = 卡槽1 + FAT32）；导出 384 KB EEPROM |
| **EEPROM 内含密钥/固件？** | ❌ **没有**（细粒度熵扫描实证） |
| **PTP 固件更新协议** | ✅ **完整还原**（含 `0x9406` 8 子码补全） |
| **`0x9606` 地址覆盖路线** | ❌ **关闭**（前置动作有高砖机风险，收益上限低） |
| **exFAT 越界写** | ❌ **已撤回**（NULL 检查阻塞） |
| **长文件名致相机重启** | ✅ **已确认**（四组对照矩阵；阈值 58–86 KB） |
| **固件解密正解** | ➡️ **物理线 JTAG/UART**（拿运行时明文，绕开密钥） |

## 三条最重要的规矩

1. **拔 SD 卡前必须在相机里正常关机**（相机分配位图**延迟写回**，直接拔卡会让位图停在旧状态）
2. **每次写卡前后都跑 `checkalloc`**（`K > 0` 立即停手）
3. **没有对照组的结论不要写进报告** —— 本项目因此撤回了两个结论

## 相机侧关键操作（服务模式）

| 动作 | 按键 |
|---|---|
| 进入服务模式 | `回放` + `AF ON` + `方向右` 同时开机 |
| 进入 INITIAL SETTINGS | `MENU/SET` + `方向右` 同时关机 |
| 完成重置退出 | 在该界面再按一次 `方向右` + `MENU/SET` |
| ⚠️ **退出前提** | **必须先拔掉 ROM BACKUP 卡（槽1/FAT32）** |
| ⚠️ **绝对禁令** | **不要按 `DISP.`**（会解除 `[Strict]`，解锁地区后缀一次性写入） |
