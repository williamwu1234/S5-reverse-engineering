# DC-S5 设置组合枚举测试计划

**目标**：找出能让 **① 触摸/实时控制可用（camctrl 12/12）** 且 **② 画面不卡不跳帧** 的相机设置组合。

---

## ⚠️ 第 0 步（必须先做）：重启相机

当前相机已经被反复测试打到 `startstream → err_busy`（会话/资源卡死），**必须先断电重启**：

1. 关机 → **拔出电池**，等 10 秒 → 装回 → 开机
2. 开机后**等相机完全就绪**（约 15 秒，屏幕出现正常拍摄画面）
3. 然后启动服务：
   ```bash
   cd "/Users/wuwilliam/Documents/ChatGPT/S5_逆向_项目总包_20261012/04_工具与脚本/s5_monitor"
   ./run.sh 192.168.x.x
   ```

> **重要纪律**：每测一组设置之间**不要连续猛测**，让相机休息 5–10 秒。
> 一旦看到 `err_busy`/`err_reject` 频发，**立即停手并重启相机** ——
> 我们已知：**相机会被高频请求打到坏状态**。

---

## 第 1 步：跑基线

```bash
python3 s5probe.py --label "基线（未改任何设置）"
```

它会输出并记录：
- **控制面**：camctrl 逐条命令的结果（几/12 可用）
- **取景面**：25 秒流的 到达速率 / 丢弃帧 / 抖动 / 最大帧间隔 / >120ms 停顿次数

---

## 第 2 步：按顺序改设置，每改一项跑一次

> **每组的做法**：在相机菜单里改设置 → 等 5 秒 → 跑 `s5probe.py --label "<改了什么>"`

### A 组：控制面（让 camctrl 可用）—— 最优先

| # | 设置项 | 相机菜单路径 | 试的值 |
|---|---|---|---|
| A1 | **触摸设置** | `设置 → 触摸 → 触摸设置` | `AF+AE`（推荐先试） |
| A2 | | 同上 | `AF` |
| A3 | **对焦模式** | 机身 AF/MF 拨杆 或 `对焦 → 对焦模式` | `AFS`（**确保不是 MF**） |
| A4 | | 同上 | `AFC` |
| A5 | **触摸快门** | `设置 → 触摸 → 触摸快门` | `ON` / `OFF` |
| A6 | **遥控拍摄界面** | 在相机上主动进入 Wi-Fi 的「遥控拍摄」画面 | — |
| A7 | **相机 LCD 状态** | 确保**相机自己在显示实时取景**（不是菜单/回放） | — |

**A 组的判据**：`camctrl_ok` 是否从 `0/12` 变成 `12/12`

### B 组：取景面（让画面不卡不跳帧）

| # | 设置项 | 相机菜单路径 | 试的值 |
|---|---|---|---|
| B1 | **省电 / 自动关机** | `设置 → 省电` | **`OFF`**（全部关掉） |
| B2 | **自动取景器切换（眼传感器）** | `设置 → 取景器/显示屏` | **关闭自动切换**（防止 LCD↔EVF 切换打断流） |
| B3 | **显示屏亮度自动调整** | `设置 → 显示屏` | 固定（不用自动） |
| B4 | **防抖 / 电子防抖** | `拍摄 → 图像稳定器` | `OFF`（减轻相机负担） |
| B5 | **录制质量 / 视频画质** | `视频 → 画质` | 先设**较低**（如 FHD 低码率）看流是否更稳 |
| B6 | **Wi-Fi 频段** | `设置 → Wi-Fi → 频段` | 5GHz ↔ 2.4GHz 各试一次 |
| B7 | **HDMI 输出** | 拔掉 / 接上 HDMI | 对照测试（HDMI 输出可能改变取景流行为） |
| B8 | **EVF/LCD 显示切换** | 手动强制用 **LCD**（不自动） | — |
| B9 | **菜单停留状态** | 测试时让相机停在**正常拍摄画面**，不要停在菜单里 | — |

**B 组的判据**：`cli_gaps_gt120 = 0` **且** `dropped = 0` **且** `cli_max_ms < 120`

### C 组：对照实验（不改设置，改环境）

| # | 变量 | 做法 |
|---|---|---|
| C1 | **相机距离** | 相机离电脑 1 米 vs 5 米 |
| C2 | **谁在看** | 电脑浏览器 vs 手机浏览器（少一跳无线） |
| C3 | **服务端参数** | `PACING_FPS` / `RESERVE_TARGET` / `PACING_KP` 调参对照 |

## 已知约束（避免无效尝试）

| 约束 | 说明 |
|---|---|
| **取景流分辨率固定 640×432** | `startstream` 无画质参数，**改相机设置也改不了这个上限**（要清晰只能走 HDMI） |
| **相机只认一个已授权会话** | 旁路探测会被 `err_reject` 拒绝，必须走本工具 |
| **相机会被高频请求打坏** | `err_busy`/`err_reject` 频发 ⇒ 立即重启相机 |
| **`camctrl` 与取景流可能互相抢占** | 本工具的探针已改为「测控制前先停流」，但仍建议环境变量分开测 |
| **回放模式无取景流** | 相机在回放模式下不推送实时取景 |
