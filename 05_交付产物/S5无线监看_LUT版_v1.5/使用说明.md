# DC-S5 无线监看 v1.0

**给 Panasonic DC-S5 用的手机/电脑无线监视器**
（官方 LUMIX Flow 不支持 S5，本工具把它的核心能力补了回来）

---

## ⚡ 三步开始

### 1. 确认网络
- 相机接入 Wi-Fi（或手机热点），记下相机 IP
- **电脑和相机要在同一个网络**里
- 验证：终端跑 `ping 192.168.x.x`（换成你的相机 IP）

### 2. 启动

| 方式 | 操作 |
|---|---|
| **最简单** | **双击 `启动.command`**，按提示输入相机 IP |
| 命令行 | `./run.sh 192.168.x.x` |

启动后终端会打印：
```
 相机      : 192.168.x.x
 节奏模式  : fixed  固定 18 fps（官方 640p 标准）
 打开浏览器：  http://<本机IP>:8080
```

### 3. 打开浏览器
**手机 / 平板 / 电脑**均可，访问终端给出的地址：

```
http://<本机IP>:8080
```

> iPhone 建议「**添加到主屏幕**」，用起来跟 App 一样（全屏、无地址栏）。
> **不需要安装任何 App。**

## ⚠️ 重要注意事项

### 🔴 三条铁律

1. **不要反复重启本服务**
   每次启动都会重新向相机申请授权。会话一旦正常，就一直用着。
2. **不要在短时间内狂点按钮**
   相机对控制命令的频率很敏感，连点会导致一段时间内拒绝响应（**等几秒再点即可**）。
   工具已内置退避重试与 3Hz 限流，正常点按不会触发。
3. **相机提示 `invalid login` 时，只能给相机断电重启**（拔电池 10 秒）

### 🟡 关于对焦

| 对焦模式 | 触摸对焦 |
|---|---|
| **AF（AFS/AFC）** | ✅ **正常工作** |
| **MF（手动）** | ❌ 触摸对焦失效（相机设计如此），请改用 **「焦点近/远」** 按钮 |

### 🟡 已知限制（已从界面移除，避免误导）

| 功能 | 原因 |
|---|---|
| ~~峰值对焦显示~~ | 相机返回 `err_param`，未找到正确参数 |
| ~~放大辅助~~ | 相机返回 `err_reject`，未找到准入条件 |

### 🟢 画质说明

**640×432 是相机的硬上限**（`startstream` 接口只有端口参数，无画质选项）。
**想要全画质监看，只能走 HDMI 输出 + 采集卡**（全分辨率、零延迟，但没有触摸对焦）。

蓝牙（BLE）**只用于配对/唤醒**，带宽仅 KB/s 级，**无法提升画质**。

## 🔧 命令行参数

```bash
./run.sh <相机IP> [端口] [节奏模式] [帧率]

# 例
./run.sh 192.168.x.x                    # 默认：8080 端口、固定 18fps
./run.sh 192.168.x.x 8090               # 换端口（默认端口被占用时）
./run.sh 192.168.x.x 8080 fixed 12      # 降到 12fps 省带宽
./run.sh 192.168.x.x 8080 adaptive      # 自适应模式（不推荐）
```

| 参数 | 默认 | 说明 |
|---|---|---|
| 相机IP | `192.168.54.1` | 相机地址 |
| 端口 | `8080` | 本机 HTTP 端口 |
| 节奏模式 | `fixed` | `fixed`=官方风格固定帧率取最新帧；`adaptive`=跟随相机速率 |
| 帧率 | `18` | fixed 模式输出帧率（官方 640p 标准） |

## 🩺 排错

| 现象 | 处理 |
|---|---|
| `端口 8080 已被占用` | 换端口：`./run.sh <IP> 8090`；或 `pkill -9 -f s5monitor.py` |
| 页面能开但**画面全黑** | 相机可能没在拍摄模式；点一下「◉拍摄」；或按「⏸停流」再「▶开始」 |
| **触摸对焦没反应** | ① 确认相机在 **AF 模式** ② 隔 1 秒再点 ③ 点 🧪 控制自检看是否可用 |
| 画面**卡顿/跳帧** | 点 📊 诊断看归因；若「下发慢」为 0 且「相机侧空档」大 ⇒ 是相机侧的突发，已由缓冲吸收 |
| 相机**变得不响应** | 停手等 30 秒；仍不行 ⇒ **相机断电重启** |
| 服务启动报 `err_busy` | 相机侧有残留会话 ⇒ **相机断电重启** |

## 🛡 安全说明

本工具**只发送**已验证的常规控制命令：
`camcmd`（拍照/录像/变焦/模式切换）、`camctrl`（触摸对焦/AE锁定）、`getstate`、`getsetting`、`startstream`/`stopstream`

**代码内置白名单，永不发送**：
固件升级、格式化、重置、关机、配置上传等任何有副作用/不可逆的命令。
