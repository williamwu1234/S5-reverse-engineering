### 2.4 CAMSET（camsetting）读写 —— **正确的分块写法**

```
读：?mode=getinfo&type=camsetting                     → 65,533 B 实时数据
写：?mode=startsenddata&type=camsetting&value=65533   → ok, method=separate, bufsize=61460
    → 分块 POST ?mode=senddata（每块 61192 B）
    → ?mode=requestsenddata
    → ?mode=endsenddata
```
- 校验和：`byte[65532] = (256 − Σ(byte[0..65531])) mod 256`（全块之和 ≡ 0 mod 256）
- 单次 65 KB POST **永远不会提交**；必须分块 `separate`
