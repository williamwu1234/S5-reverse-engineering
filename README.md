## 结论速览

1. **7 条结论已被推翻**（见 `01_唯一权威调用文档.md` §1），旧文档凡涉及处一律按新口径。
2. **工具真实路径是 `campaign2/`**，不是旧文档写的 `cam_cgi/`、`exfat/`。
3. **网络 RCE 全阴性**：dlna 29 项 + `cam.fcgi` + psm + lighttpd 逐一比对后，2 个真 bug 均卡在"触发前置不成立"。
4. **AES 密钥：◐ 离线希望渺茫（非终局）**。`+0x200` 偏移修正 + 两组阳性对照重跑 ⇒ 真实固件 0 命中 = **真阴性**，封死"文件内派生候选"这一层。
5. **Linux 内核 3.18.18 零加固 + `/dev/mem` 开放**（无 STRICT_DEVMEM / KASLR / 栈保护 / LSM）；`Linux root → /dev/mem → 读解密后 program 明文` 这条链**已在 QEMU 端到端实测跑通**。
6. **但远程可达面无触发入口** ⇒ 软件侧已到边界，**唯一有确定增量的方向仍是硬件**（拆机 UART / Tether 抓包）。
