## 3. 通过包管理器安装的东西（**只有一个**）

| 包 | 版本 | 装法 | 用途 / 结果 |
|---|---|---|---|
| **`ipatool`** | **2.7.0** | `brew install ipatool` | 尝试下载 iOS `LUMIX Sync` 的 IPA 以逆向蓝牙实现 |

**关于 ipatool 的结论**：
- 它需要 **Apple ID 登录**（凭据存 macOS 钥匙串），登录态在本会话中**未能被工具进程读取**；
- 更关键的是：App Store 的 IPA **主程序是 FairPlay 加密的**，即使下载成功也反编不出
  Swift/ObjC 代码——**收益低于未加密的 Android APK**；
- 因此**最终改走 Android APK 逆向**（`03_解包_APK/`），蓝牙协议由此完整还原。

> 结论：**ipatool 不是复现本项目的必要依赖**，可省略。

## 7. 最小复现环境

只跑 **Wi-Fi/cam.cgi 主流程**，你只需要：

```bash
# 1) 任意 macOS / Linux + Python 3.8+
# 2) 与相机同一局域网，且知道相机 IP
# 3) 无需安装任何第三方包
python3 02_工具与脚本/cam_cgi/persist.py verify demo
```

要跑**蓝牙**或 **USB PTP**，再加：

```bash
# 蓝牙（macOS，含 Xcode Command Line Tools）
swiftc -framework CoreBluetooth -framework Foundation -o ble_scan ble_scan.swift
# USB PTP（macOS，含 CLT 的 clang）
clang -framework IOKit -framework CoreFoundation -o s5_ptp_raw s5_ptp_raw.c
```

**都需要**：系统给终端/宿主 App 授予「蓝牙」权限（BLE）；
USB 场景需先确认没有云盘类 App 占用相机设备（见下）。

## 8. 环境层面的两个坑（实测）

1. **第三方 App 抢占 USB 设备**：夸克网盘（`QuarkCloudDrive`）曾在相机 USB 设备上挂了
   `IOUserClient`（`ioreg` 里可见 `IOUserClientCreator`），导致 PTP 完全无响应。
   做 USB 调试前先 `ioreg -w0 -l -r -n DC-S5 | grep IOUserClientCreator` 检查并退出占用者。
2. **定位权限**：macOS 14+ 下 `CoreWLAN` 读不到 SSID/BSSID（返回 nil），
   需要给终端开「定位服务」权限，否则无法从 Wi-Fi 侧识别相机热点。

## 9. 本轮新增：macOS **原始磁盘设备**的访问限制（exFAT 实验必需）

做 exFAT 越界写实验必须**读写 SD 卡的原始设备**（`/dev/diskNsM`、`/dev/rdiskNsM`），
macOS 对此有**双重保护**：

| 层 | 事实 | 后果 |
|---|---|---|
| **Unix 权限** | `brw-r----- root operator` —— 只有 root 或 `operator` 组成员可访问 | 普通用户直接 `Permission denied`（本项目主用户**不在** `operator` 组） |
| **TCC** | 原始磁盘访问还需进程具备**「完全磁盘访问」** | 即使用 `osascript ... with administrator privileges` 拿到 **uid=0**，仍报 `Operation not permitted` |

⇒ **自动化/AI 进程两条路都过不去**，这些命令**必须由人在终端里 `sudo` 执行**。

**可选放宽方式**（一次性，长期有效）：

```bash
# 让当前用户能【只读】原始设备（写入仍需 root）
sudo dseditgroup -o edit -a $(whoami) -t user operator
# 或在「系统设置 → 隐私与安全性 → 完全磁盘访问权限」里勾选所用终端
```

**另一个 TCC 陷阱**：`osascript` 提权后的 root shell **访问不了 `~/Documents` 等受保护目录**
（报 `Operation not permitted (126)`）—— 所以脚本要放到 **`/tmp`** 之类不受保护的位置再执行。

> 本项目的 exFAT 工具即因此被复制到 `/tmp/s5exfat/` 运行：
> ```bash
> mkdir -p /tmp/s5exfat && cp 02_工具链/exfat/* /tmp/s5exfat/ && chmod +x /tmp/s5exfat/*
> sudo bash /tmp/s5exfat/s5_exfat_test.sh verdict /dev/disk8s1
> ```
