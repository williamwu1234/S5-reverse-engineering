## 工具链速查

```bash
mkdir -p /tmp/s5exfat && cp 02_工具链/exfat/* /tmp/s5exfat/ && chmod +x /tmp/s5exfat/*

# 一致性体检（写卡前后都必须跑，K 必须为 0）
sudo bash /tmp/s5exfat/s5_exfat_test.sh checkalloc /dev/disk8s1

# exFAT 结构诊断（全部只读）
sudo bash /tmp/s5exfat/s5_exfat_test.sh info    /dev/disk8s1
sudo bash /tmp/s5exfat/s5_exfat_test.sh bitmap  /dev/disk8s1
sudo bash /tmp/s5exfat/s5_exfat_test.sh entries /dev/disk8s1 /DCIM/100_PANA
sudo bash /tmp/s5exfat/s5_exfat_test.sh chain   /dev/disk8s1 <簇号>

# 目录项构造（复现长名崩溃 / 做对照实验）
sudo bash /tmp/s5exfat/s5_exfat_test.sh mkentries /dev/disk8s1 360 240 0
sudo bash /tmp/s5exfat/s5_exfat_test.sh mkdeleted /dev/disk8s1 6464
sudo bash /tmp/s5exfat/s5_exfat_test.sh mkspray   /dev/disk8s1 360 17 0
sudo bash /tmp/s5exfat/s5_exfat_test.sh trimdir   /dev/disk8s1 6
```

## 三条硬规矩（血的教训）

1. **拔 SD 卡前必须在相机里正常关机** —— 相机分配位图**延迟写回**，直接拔卡会让位图停在旧状态
2. **每次写卡前后都跑 `checkalloc`** —— `K > 0` 立即停手
3. **没有对照组的结论不要写进报告** —— 本日因此撤回了两个结论
